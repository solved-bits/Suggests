# Issue Submission Guidelines

You can use this repository when you want to suggest something about **solvedbits.org**, report technical issues, or request content updates. Please follow the procedure below to submit a GitHub Issue.

---

## Submission Procedure

1. **Review Existing Issues**  
   Navigate to the **[Issues](../../issues)** tab at the top of this repository to verify whether a similar suggestion or bug has already been reported.

2. **Initialize a New Issue**  
   Click the **New issue** button located on the upper right side of the Issues page.

3. **Provide a Descriptive Title**  
   Summarize your feedback concisely in the title field. Please include one of the following prefixes to assist with categorization:
   - `[Bug]` — Functional errors, broken assets, or typographical errors
   - `[Feature]` — New feature proposals or UI/UX enhancements
   - `[Content]` — Updates to team member profiles, sponsor information, or site copy

4. **Detail the Request**  
   Provide a clear and thorough explanation in the description field. You may use the standard templates provided below.

5. **Submit the Issue**  
   Click **Submit new issue** to finalize your submission. The administrative team will review your request and respond accordingly.

---

## Issue Templates

### Bug Report
```markdown
### Description
Provide a clear and concise description of the issue encountered.

### Environment
- **Device / OS:** (e.g., Windows 11, macOS, iOS)
- **Browser:** (e.g., Chrome, Safari, Edge)
- **URL:** (e.g., http://solvedbits.org)

### Visual Reference
Attach relevant screenshots if applicable.
```

### Feature or Content Request
```markdown
### Summary
Describe the proposed feature or the specific content modification requested.

### Rationale
Explain how this change will improve solvedbits.org.
```
